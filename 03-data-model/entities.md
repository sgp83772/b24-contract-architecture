| Сущность | Тип в Bitrix24 | Почему так |
|---|---|---|
| Контрагент | Компания (CRM) | Стандартная сущность, есть связи с CRM |
| Договор | Смарт-процесс | Нужны стадии, кастомные поля, права, связь с CRM |
| Спецификация | Смарт-процесс | Позиции договора, много записей на один договор |
| Счёт | Смарт-процесс | Отдельный жизненный цикл, связь с 1С |
| Акт/УПД | Смарт-процесс | Закрывающий документ по счёту |
| Платёж | Смарт-процесс | Финансовое событие, связь со счётом |
| Претензия | Смарт-процесс | Отдельный процесс, SLA |
| Задача согласования | Задача | Использует штатный бизнес-процесс |
| Версия документа | HL-блок | Много версий на один договор, файлы в S3 |
| Звонок | Телефония (штатная) | Интеграция с Mango Office |
