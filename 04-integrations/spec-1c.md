# Интеграция Bitrix24 ↔ 1С:УПП

## Направления
- 1С → Bitrix24: Контрагент, Договор, Счёт, Платёж (создание/обновление)
- Bitrix24 → 1С: Платёж (подтверждение), Претензия (уведомление)

## Маппинг полей (фрагмент)
| Bitrix24 | 1С | Тип | Направление |
|---|---|---|---|
| Контрагент.INN | Контрагент.ИНН | string | 1С→B24 |
| Контрагент.NAME | Контрагент.Наименование | string | 1С→B24 |
| Договор.NUMBER | Договор.Номер | string | 1С→B24 |
| Договор.AMOUNT | Договор.Сумма | decimal | 1С→B24 |
| Договор.STATUS | Договор.Статус | enum | 1С→B24 |
| Платёж.AMOUNT | Платёж.Сумма | decimal | B24→1С |

## Обработка ошибок
- Retry: 3 попытки, задержки 1с / 5с / 25с (экспоненциальная)
- После 3 неудач — сообщение в DLQ RabbitMQ, алерт в Telegram-чат архитектора
- Идемпотентность: ключ `{entity}:{id}:{updated_at}` в Redis (TTL 24ч)

## Частота
- Контрагенты: раз в час (cron)
- Договоры, счета: real-time по вебхуку из 1С
- Платежи: раз в 15 минут (batch)
