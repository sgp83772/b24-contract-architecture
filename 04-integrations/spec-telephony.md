# Спецификация интеграции: Bitrix24 ↔ Mango Office (телефония)

**Версия:** 1.0
**Дата:** 2026-11-02

## 1. Назначение
Фиксировать все входящие и исходящие звонки в карточке контрагента, привязывать запись разговора к договору.

## 2. Направление обмена
Mango Office → Bitrix24 (одностороннее, webhook).

## 3. События
| Событие Mango | Что делаем в Bitrix24 |
|---|---|
| `call.started` | создаём запись в сущности `Звонок` (status=in_progress) |
| `call.ended` | обновляем длительность, ссылку на запись |
| `call.missed` | создаём задачу «Перезвонить» ответственному |

## 4. Маппинг полей
| Mango | Bitrix24 | Тип |
|---|---|---|
| call_id | Звонок.EXTERNAL_ID | string |
| call_date | Звонок.DATE | datetime |
| duration | Звонок.DURATION | int (сек) |
| recording_url | Звонок.RECORDING_URL | string |
| phone | используется для поиска Контрагента по телефону | string |
| direction | Звонок.DIRECTION (in/out) | enum |

## 5. Логика определения контрагента
1. Приходит `phone` из Mango.
2. Ищем в CRM: `Компания.PHONE = phone` ИЛИ `Контакт.PHONE = phone`.
3. Если найдено — привязываем звонок к компании/контакту.
4. Если не найдено — создаём **Лид** с источником «Телефония», привязываем звонок к лиду.
5. Если телефон пустой (скрытый номер) — звонок привязывается к «Неопознанный».

## 6. Обработка ошибок
- Webhook от Mango должен отвечать `200 OK` быстрее, чем за 2 секунды.
- Если обработка упала — Mango повторит через 5 мин, потом через 30 мин.
- После двух неудач — запись в HL-блок `integration_log`, статус `failed`.

## 7. Ограничения
- Запись разговора не хранится в Bitrix24 — только ссылка на S3/Mango.
- Срок хранения ссылок — 90 дней (политика Mango).
